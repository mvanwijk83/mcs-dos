  About the expansion pack
----------------------------------------
This disk contains extra material not
included in the standard MCS-DOS
distribution.

The included content is intended to work
with MCS-DOS version 1.0.

Dogfooding note: this disk was fully
prepared using MCS-DOS 1.0 on a multiple
disk drive setup. Only the blank D64
image was created externally.


  Alternative character sets
----------------------------------------
Reproductions of several classic 8- and
16-bit machines to customize your
MCS-DOS shell. Simply copy one or more
of these files to your MCS-DOS system
disk and add SET PROMPT=NAME to your
AUTOEXEC.BAT (where NAME is the .CPI
file name without extension).

AMIGA.CPI
  Topaz/8 Amiga font (Kickstart 1.0).
ATARIST.CPI
  The 8x8 variant of the Atari ST
  system font (TOS 2.06).
PET.CPI
  Commodore PET/VIC-20 system font.
ZXSPECTRUM.CPI
  Sinclair ZX Spectrum system font.


  Theme files
----------------------------------------
Enables themes imitating some classic
8- and 16-bit systems. To use a theme,
replace the AUTOEXEC.BAT on your MCS-
DOS system disk with one of these .BAT
files, and copy the corresponding .CPI
file to the same disk.

AMIGA.BAT
  White on blue with Topaz/8 font and
  DFn:-style shell prompt.
ATARIST.BAT
  Black on green with Atari ST system
  font. Uses a DOS-style prompt.
PET.BAT
  Green on black with the PET system
  font. Uses a Commodore-style prompt.
PLUS4.BAT
  Black on white with a light blue
  border and the default system font.
  Uses a Commodore-style prompt.
VIC20.BAT
  Dark blue on white with a cyan border
  and the PET system font. Uses a
  Commodore-style prompt.
ZXSPECTRUM.BAT
  Black on light gray shell with ZX
  Spectrum system font. Uses a DOS-style
  prompt.
