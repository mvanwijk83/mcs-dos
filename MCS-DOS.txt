MCS-DOS
  An MS-DOS-like shell for the Commodore 64/128.
  (C)2026 MCS


*** List of commands ***

BASIC
  If in BASIC mode, prompts the user for a BASIC command to execute.

BEEP
  Emits a squarewave beep. Can specify duration in milliseconds (200 if not specified).
  Usage examples:
    BEEP
    BEEP 1000

CHKDSK
  Shows basic stats of disk: space free, space used, whatever from original CHKDSK that applies. Shows both bytes and blocks.

CLS
  Clears current screen.

COLOR
  Sets terminal color.
  - /FORE for foreground (text) color
  - /BACK for background color. This also changes the border color accordingly.
  - /BORDER for border color.
  - Standard BASIC color numbers are used.

  Usage examples:
    COLOR /FORE:7
    COLOR /BACK:3
    COLOR /BORDER:15
    COLOR /FORE:7 /BACK:3 /BORDER:15

COPY
  Copies a file to the same disk under a different name, or to another drive. Uses semantics as close to original DOS as possible.
  Usage example:
    COPY TURRICAN TURRICAN-COPY

DEL
  Deletes a file. Ask confirmation with Y/N.
  Usage example:
    DEL EXPENSES AUG 2026

DELETE
  Alias of DEL.

DIR
  - Shows PRG, SEQ, etc. as if they are extensions.
  - Disk name is shown as "volume label".
  - Pagination by default (as if MS-DOS DIR was called with /P).
  - Wildcards should be supported.
  - Supported MS-DOS switches: /B /L /O /W
  - /O only needs to support alphabetic sorting.

DISKCOPY
  Copies the complete contents of a disk to another disk.
  Usage example:
    DISKCOPY 8: 9:

ECHO
  Displays text.
  Usage example:
    ECHO Hello world

EDLIN
  Launches a simple line editor; no commands. Ctrl-C to stop editing; it will prompt the user whether to save the file, and
  ask for a filename if one wasn't supplied at invocation.
  Usage examples:
    EDLIN
    EDLIN MYNEWFILE

ERASE
  Alias of DEL.

EXIT
  Exits MCS-DOS and returns user to BASIC.

FORMAT
  Formats a disk. User is asked for confirmation and prompted for volume label.
  Usage example:
    FORMAT 8:

HELP
  Outputs a plain list of commands (multi-column to save screen real estate). Or, the name of a command can be used as an
  argument: e.g. HELP DIR is equivalent to DIR /?.

LABEL
  Renames a disk. Prompts user for name if omitted from command.
  Usage example:
    LABEL 8:
    LABEL 9: MY NEW DISK

MEM
  Shows current memory usage.

MOVE
  Moves a file from one disk to another.
  Usage example:
    MOVE ELITE 9:

PAUSE
  Displays a message prompting the user to press a key to continue.

PRINT
  Sends a file to a connected printer.

REM
  Remark command for use in batch files.
  Usage example:
    REM Lorem ipsum dolor sit amet

REN
  Renames a file.
  Usage eample:
    REN MULE MULE2

RENAME
  Alias of REN.

RUN
  Runs a program from disk. (This exits MCS-DOS.)
  Usage example:
    RUN TURRICAN

TYPE
  Displays the contents of a file. Output is paginated (as if invoked with | MORE).
  Usage example:
    TYPE MY EXPENSES AUG2026

VOL
  Displays current disk's volume name and serial number.

WIPEDISK
  Deletes all files from disk. Echoes file name to terminal as deletion is completed. If the drive number was ommited,
  the current disk will be wiped.

VER
  Shows MCS-DOS version and copyright information.

VERSION
  Alias of VER.


*** Common to all commands ***
Command-line switch /? to display help for command (can also be invoked with the HELP command).


*** Startup ***
Upon starting the shell, prompt the user to select one of the color schemes. RETURN picks the default (1).
  1. Classic DOS (light blue on black)
  2. High-contrast (white on black)
  3. Terminal green (green on black)
  4. BASIC blue (light blue on dark blue)

Border color matches foreground color in each case.


*** Terminal ***
  - Prompt is $p$g style. Use C64 drive numbers instead of letters (e.g. 8:, 9:).
  - To switch drives, also classic DOS style, but with drive numbers instead of letters.
  - DOSKEY-style command history (up to ten commands). Allow cursor keys up/down to recall them.
  - No support for piping, redirecting etc.
  - Executing a program requires using the RUN command; no DOS-style "just type in the name and it runs".
  - Ctrl-C for abort.
  - When typing a command and a file name is expected, the user should be able to auto-complete using the
    Commodore key. Pressing repeatedly brings up the next suggestion, if applicable. (This probably necessitates
    caching disk file entries.)


*** Batch files ***
Batch files should be supported. File name will always include .BAT even if not originally specified by user upon creation.
This makes it recognizable on disk if a user uses DIR. It only needs to support sequences of plain MCS-DOS commands, it is
not intended as a full-fledged script file. ECHO is supported, as well as @ECHO OFF.
