                Changelog

  1.0 Preview (13-Sep-2026)
----------------------------------------
Preliminary public release.

  1.0 (15-Sep-2026)
----------------------------------------
* Fixed a bug where DEL did not report
  failed deletion when a file is
  locked.
* Removed /S switches (omit decimal
  separators) from MEM and CHKDSK as
  they were of limited utility.
* Small memory usage reduction by
  various code optimizations.
* General code cleanup.
* Finalized inline and offline docu-
  mentation.
* Finalized release package.
* Source code release.

  1.01 (19-Sep-2026)
----------------------------------------
* Added /P switch to COPY (overwrite
  without user confirmation).
* ECHO text ending in ; will omit the
  line terminator (use ;; to escape).
* Extended memory usage report produced
  by MEM.
* Press RESTORE on boot screen for "safe
  mode" (skips executing AUTOEXEC.BAT).

  2.0 (dd-Mmm-2026)
----------------------------------------
* MCS-DOS is now distributed as an Easy-
  Flash cartridge image. The cartridge
  can be used as any other storage
  device and contains 64k of writeable
  space.
* Support added for CONFIG.SYS to
  configure boot behaviour.
* The command help library is no longer
  represented as a file (COMMANDS.HLP)
  but stored as internal cartridge data.
* The BASIC command replaces EXIT. It
  enters the C64 BASIC environment and
  offers a wedge to return to the shell.
* Changed the DOS-style "R" file
  attribute letter for the file lock bit
  to "L", matching actual C64 behaviour.
* Added head, tail and hex view options
  to TYPE (/H, /T, /HEX).
* Added /P switch to MOVE to suppress
  file overwrite prompt.
* Added DISKINIT command to refresh
  drive cache and status, equivalent to
  the CBM-DOS INITIALIZE command.
* DELeting files with a wildcard will
  now prompt for individual confirmation
  for each matching file, unless /P was
  specified.
* Added file redirection support for
  FIND, and removed it from HELP.
* REU test in MEM removed due to
  register overlap between the EasyFlash
  RAM and the REU registers.
* Revised some system messages.
