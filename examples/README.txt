MCS-DOS @VERSION@

Type HELP for commands.
RUN HELLO.BAT runs a batch file.
EDIT NOTES creates a text file.
RUN/STOP finishes editing.
RUN DEMO launches a BASIC program.

Use AUTOEXEC.BAT for preferences.
COLOR /PRESET:5 selects BASIC blue.
AUTOEXEC.BAT runs at disk startup.
At 0:>, enter 8: to select a disk.

Enjoy your Commodore DOS prompt!
