# MCS-DOS Extras

This folder contains extra content to enhance your MCS-DOS installation. Simply
copy whatever files you like to your MCS-DOS system disk. At this moment this
folder only contains alternative character sets, but additional utilities and
preset shell themes may arrive as well.

## Contents

* **AMIGA.CPI** &ndash; The Topaz/8 font from the Amiga Kickstart 1.0 ROM.
* **ATARIST.CPI** &ndash; The 8x8 variant of the Atari ST ROM font.
* **PET.CPI** &ndash; The ROM character set from the Commodore PET. The VIC-20 uses an identical set, except that the backslash (`\`) is substituted by the British pound symbol (`£`).
* **ZXSPECTRUM.CPI** &ndash; The ROM character set from the Sinclair ZX Spectrum.

Character sets have been converted from Rob Hageman's "Hoard of Bitfonts"
repository (https://github.com/robhagemans/hoard-of-bitfonts). Usage complies
with their terms of use.
