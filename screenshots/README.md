# Screenshots

This folder contains some screenshots demonstrating some basic MCS-DOS functionalities.

* `screen00.jpg` &ndash; MCS-DOS boot screen
* `screen01.jpg` &ndash; System test and startup
* `screen02.jpg` &ndash; Listing a directory on diskette.
* `screen03.jpg` &ndash; Running the `CHKDSK` and `MEM` commands.
* `screen04.jpg` &ndash; Some file operations: redirecting a sorted list of file names to a text file, copying the file to a different disk, and viewing the contents.
* `screen05.jpg` &ndash; The internal text editor with `AUTOEXEC.BAT` opened in it.
* `screen06.jpg` &ndash; A highly customized shell with a custom character set and colors matching the ZX Spectrum (how cursed!).

Screenshots 04 to 06 were previously taken with 1.0 version, but still accurately demonstrate existing functionality.
